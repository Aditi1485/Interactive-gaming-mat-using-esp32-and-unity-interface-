🔐 Image Encryption & Decryption

Using Logistic Map | Medical Image Security

📌 Project Overview

This project focuses on securing digital medical images using a logistic map-based chaotic encryption technique. The logistic map generates highly random sequences that are used to encrypt image pixels, making the image unreadable to unauthorized users. The encrypted image can be decrypted using the correct key, ensuring both security and reliability. This approach is highly suitable for protecting sensitive medical data.

🎯 Objectives

  • Ensure secure image transmission
  • Prevent unauthorized access
  • Apply chaos theory in encryption
  • Maintain data confidentiality

🧠 Concept

The logistic map is defined as:

x(n+1) = r × x(n) × (1 − x(n))

This equation generates chaotic sequences that are highly sensitive and random. These sequences are used to encrypt pixel values of the image.

⚙️ Working Process

  • Input image is taken
  • Converted into grayscale
  • Logistic map generates chaotic sequence
  • Image is encrypted
  • Decryption restores original image

📌 Conclusion

This project demonstrates the use of chaos theory for secure image encryption. The logistic map provides high randomness and sensitivity, making the encryption strong and difficult to break. The system ensures that the image is securely transformed into an unreadable format and can be accurately recovered using the correct key. This makes the approach reliable and effective. Compared to traditional methods, chaos-based encryption enhances security and is highly suitable for protecting sensitive medical images.
