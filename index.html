🎮 Interactive Gaming Mat

Using ESP32 & Unity Interface

Developed by Aditi

📌 Project Overview

This project presents an interactive gaming system that converts real-world physical movements into digital game actions using ESP32 and Unity. Pressure sensors placed inside the mat detect user steps and send signals to the ESP32 microcontroller. The ESP32 processes these signals and communicates with the Unity game, enabling real-time interaction. This creates an immersive gaming experience where users control the game using their physical movements.

🎯 Objectives

  • To design an interactive gaming system using real-world input
  • To integrate ESP32 hardware with Unity software
  • To detect movement using pressure sensors
  • To enable real-time communication
  • To create an engaging gaming experience

🧩 Components Used

  • ESP32 Microcontroller
  • Pressure Sensors / Velostat Mat
  • Unity Game Engine
  • USB / Serial Communication
  • Power Supply

⚙️ Working Process

  • User steps on the mat
  • Sensors detect pressure input
  • ESP32 processes signals
  • Data sent to Unity
  • Game responds instantly

🖼️ Results

The interactive gaming mat system was successfully implemented and tested, demonstrating accurate detection of user movements and seamless interaction with the Unity-based game environment.

When a user steps on different regions of the mat, the pressure sensors respond instantly and send signals to the ESP32 microcontroller. These signals are processed and transmitted to the Unity application, where corresponding game actions such as movement, jumping, and control are executed in real time.

The system exhibits high responsiveness with minimal delay, ensuring a smooth and engaging gaming experience. The accuracy and consistency of the input detection make the system highly reliable.

This system can be applied in gaming, fitness training, rehabilitation therapy, and interactive learning systems, showing its versatility and real-world usability.
